# Documentación del proyecto

Golden Street Moving es un sitio landing en Laravel 10 con un formulario de cotización de mudanzas y un panel de administración simple para dar seguimiento a esas cotizaciones.

Índice:

- [setup.md](setup.md) — cómo levantar el proyecto en local (dependencias, `.env`, base de datos, comandos de build/test).
- [architecture.md](architecture.md) — estructura general del backend (Laravel) y del frontend (Blade + Vue por componentes), y cómo se comunican.
- [booking-flow.md](booking-flow.md) — flujo completo de una cotización: formulario público, endpoint de la API, envío de correo y panel de administración.

Para instrucciones dirigidas específicamente a Claude Code al trabajar en este repo, ver [../CLAUDE.md](../CLAUDE.md).
